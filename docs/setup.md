Prerequisites



Node.js (v18 or higher)



Git



Expo Go app installed on iOS or Android (for mobile testing)



Step-by-Step Setup Guide



Clone the repository



PowerShell

git clone https://github.com/MayMourad/SMAC-ADNOCMZ-Khutwa.git

cd SMAC-ADNOCMZ-Khutwa

Install dependencies



PowerShell

npm install

Start the development server



PowerShell

npx expo start

Run on your device



Open the Expo Go app on your phone.



Scan the QR code displayed in your PowerShell terminal or browser window.
